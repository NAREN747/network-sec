Perimeter Network Architecture

LAN / DMZ / Internet Zones — VLAN Segmentation, Subnetting & Zone Policy Matrix

Zone Segmentation Summary

  • • Internet (External): 203.0.113.0/24 — Untrusted, attackers, public users
  • • DMZ: 10.10.20.0/24 (VLAN 20) — Public-facing: Web, DNS, Mail, WAF
  • • LAN: 10.10.10.0/24 (VLAN 10) — Employees, workstations, internal apps, AD
  • • Management: 10.10.0.0/24 (VLAN 99) — Router, Switch, Firewall, SIEM, Admin

Router-on-a-Stick (RoAS) Config

  • • Single physical link (Gi0/0) trunked to Core Switch
  • • Gi0/0.10 — encap dot1Q 10 — 10.10.10.1/24 (LAN gateway)
  • • Gi0/0.20 — encap dot1Q 20 — 10.10.20.1/24 (DMZ gateway)
  • • Gi0/0.99 — encap dot1Q 99 — 10.10.0.1/24 (Mgmt gateway)
  • • WAN: Gi0/1 — 203.0.113.2/30 → ISP 203.0.113.1
  • • Default route: ip route 0.0.0.0 0.0.0.0 203.0.113.1

Zone Policy Matrix (ACL Logic)

  • • LAN → DMZ: Permit TCP 80,443 (web access)
  • • LAN → Internet: Permit TCP 80,443, UDP 53 (web, DNS)
  • • LAN → Mgmt: Permit TCP 22 (SSH) FROM admin host only
  • • DMZ → Internet: Permit TCP 80,443, UDP 53,123 (updates, NTP)
  • • DMZ → LAN: DENY ALL (no initiated connections inward)
  • • Internet → DMZ: Permit TCP 80,443 (public web), ESTABLISHED
  • • Internet → LAN/Mgmt: DENY ALL
  • • Mgmt → All: Permit SSH, HTTPS, SNMP, Syslog for mgmt
